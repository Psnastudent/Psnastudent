## 🏆 Highlighted Projects

Here are some of the projects I've been working on:

- 🎓 **[OD-management](https://github.com/Psnastudent/OD-management)**: A web-based platform to apply for On-Duty (OD) efficiently. Built with TypeScript.
- 🖐️ **[Gesture-Controlled-Holographic](https://github.com/Psnastudent/Gesture-Controlled-Holographic)**: An innovative project focusing on controlling holographic elements through physical gestures. Built with JavaScript.
